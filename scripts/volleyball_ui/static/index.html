Параметры запуска нейросетей
Контекст и источники видео

Параметры анализа общие для проекта, диапазоны задаются отдельно для каждого видео.

МячVballNet · модель, порог, движок

VballNet находит мяч; RAVEL анализирует игроков отдельно. Порог ниже — больше находок и ложных срабатываний. Реальную скорость нейросетей на CPU и GPU смотрите в «Бенчмарке»: ускорение всего анализа зависит также от декодирования и RAVEL.

ИгрокиRAVEL · детекция и стабильность ID
Обнаружение и фильтрация

Здесь сохраняются предсказания моделей. Порог Touch — минимальная вероятность, попадающая в сохранённые действия RAVEL; порог итоговых касаний и их объединение настраиваются позже, на CPU. Слишком высокий порог GPU нельзя понизить задним числом, если сырые вероятности не сохранены.

Удержание и связывание Track ID
Личности · CPU ReID после инференса

Группы объединяются только при подтверждённом визуальном сходстве и отсутствии пересекающихся треков. Автопривязка требует проверенных фото/ID из базы и строгого отрыва от второго кандидата. Автоматические привязки не становятся эталонами без ручного подтверждения. Эти CPU-настройки не требуют повторной детекции RAVEL.

Скорость и ресурсыCUDA · кадры · CPU
Ресурсы GPU · ONNX Runtime CUDA

Параметры CUDA применяются к VballNet и RAVEL на GPU. Лимит арены не ограничивает всю VRAM: фактическое потребление может быть выше.
