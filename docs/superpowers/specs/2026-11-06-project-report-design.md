# Отчёт проекта

Сверху показана статистика всех видео проекта для выбранной версии обработки: игроки, общее число уникальных касаний и распознанные действия.

Ниже расположены карточки игроков в три столбца; шесть игроков занимают два ряда. На узких экранах число столбцов уменьшается. Число карточек соответствует реальному составу проекта, без ограничения шестью игроками.

Карточка содержит фото или заглушку, имя, общее число касаний и категории из CPU-фильтра предпросмотра: атаки, блоки, подачи, приёмы, верхние передачи. Нулевые значения видны. Счёта матча нет.

Общее число касаний включает действия с определённым и неопределённым типом. Касание и классификация одного контакта не суммируются как два контакта. Совпадение по времени у разных игроков само по себе не служит основанием объединять события. Источник событий и правила соответствия используются совместно с предпросмотром.

Отображаются все игроки, указанные при создании проекта, включая игроков с нулём касаний. Для каждого суммируются события всех розыгрышей всех видео проекта в выбранной версии обработки. Альтернативные версии одного анализа не складываются. Исключённые ID не учитываются. Нераспределённые касания входят в сводку проекта, но не приписываются игрокам.

В углу каждой карточки показан коэффициент активности: общее число уникальных касаний игрока, делённое на медиану общего числа уникальных касаний всех игроков состава проекта, включая нулевые значения. Для чётного числа игроков медиана равна полусумме двух центральных значений отсортированного ряда. Отображаются два знака после запятой: 1,00 соответствует медиане, 1,50 означает на 50% больше, 0,50 — на 50% меньше. Подсказка объясняет формулу. При нулевой медиане коэффициент не определён: отображается «—» с пояснением, без деления на ноль. До появления результатов также отображается «—».

## Подходы

Сохранение нынешней узкой колонки карточек не соответствует запрошенной сетке. Выбранная пользователем компоновка: полноширинная сводка сверху и сетка карточек снизу. Используются существующие Python API и интерфейс JavaScript/CSS без новых зависимостей.

## Проверка

Проверить пересечение касания и атаки, несколько разных контактов, одинаковые имена разных игроков, объединённые ID и суммирование всех розыгрышей нескольких видео. Проверить полный состав проекта, включая нулевые значения, шесть карточек в сетке 3 × 2 и пустое состояние. Проверить коэффициент для нечётного и чётного состава, нулевую медиану и отсутствие результатов.
