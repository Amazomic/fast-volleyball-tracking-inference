# Сопоставление игроков проекта

Пользователь подтвердил компактное отображение игроков с фотографией, ID, именем и сходством. Каждый ID сравнивается с подтверждёнными образцами игроков проекта; выбирается максимальное сходство. Автопривязка выполняется выше пользовательского порога, ниже остаётся ручной выбор. При равенстве лучших оценок нужен ручной выбор. Одновременные люди не получают одну личность. Ручные назначения сохраняются; автоматические назначения не становятся обучающими образцами.

## Подходы

Сохранение минимального разрыва между кандидатами уменьшает автоматизацию; пользователь выбрал максимальное сходство с общим порогом. Используется существующий ReID по внешнему виду, без отдельной системы распознавания лиц.

Для CPU-шаблона контрольный эпизод №74, 00:31:26–00:31:56: ориентир пользователя 17 касаний и 5 игроков. Настройки меняются по результатам сравнения сохранённых предсказаний; число в интерфейсе не подменяется константой.
