# Project player tracks

Цель: показывать Track ID всех записей проекта, сохранить независимость одинаковых номеров и вынести четыре счётчика наверх.

Реализация: отдельный модуль объединяет отчёты по видео и хранит исходные видео, версии анализа и номера ID. Операции привязки, исключения, фотографии и ReID маршрутизируются по исходному контексту. Отчёт для остальных разделов остаётся отдельным.
