# Rally Ground Boundaries Implementation Plan

**Goal:** Предлагать конец розыгрыша по наблюдаемому отскоку от площадки, не меняя исходные данные и не выдавая гипотезу за подтверждённый факт.

**Architecture:** Rust проверяет ограниченное окно наблюдений мяча до и после перелома, разметку площадки и близость игроков; потоковая реконструкция с задержкой сохраняет границу в новой CPU-версии. Пропуски, выбросы и контакт рядом с игроком не считаются доказанным падением.

**Tech Stack:** Rust, существующие CPU replay и калибровка площадки.

- [x] Проверить падение, касание игрока, свободный полёт и неверные координаты синтетическими тестами.
- [x] Подключить кандидата границы к CPU-реконструкции и версионировать повторное использование результатов.
- [ ] Проверить сохранённые данные `new2` и полный набор проектных проверок, документировать ограничения.
