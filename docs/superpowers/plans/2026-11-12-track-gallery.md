# Галерея Track ID

1. Сохранить несколько разных наблюдений каждого Track ID в проверенном индексе CPU, ограничив их число и сохраняя привязку к кадрам розыгрышей.
2. Расширить существующий маршрут фотографий выбором образца и проверить отсутствие автоматического изменения данных.
3. Оставить на вкладке сетку ID и переключатель отдельных и сгруппированных ID; по нажатию на фото показывать следующий кадр того же ID.
4. Проверить Rust, UI, переключение режимов и фотокадров; перезапускать студию только при отсутствии активных задач.
