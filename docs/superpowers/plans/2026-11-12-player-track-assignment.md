# Привязка Track ID к игрокам проекта

**Цель:** вернуть список игроков проекта справа и позволить вручную привязать отдельный ID или группу с сохранением фотографии игроку.

**Архитектура:** использовать существующие маршруты Rust для привязок и фотоальбома; интерфейс показывает только участников выбранного проекта и сообщает об отдельно возникших ошибках сохранения фотографии. Исходный CPU-снимок и прочие проекты не изменяются.

1. Проверить отображение состава проекта, карточек ID и групп, а также контракт сохранения фотографии.
2. Добавить проверку выбора игрока проекта и сценария привязки с сохранением фотографии; убедиться, что проверка обнаруживает отсутствие поведения.
3. Восстановить правую колонку и кнопку на карточках, подключить сохранение фото через существующий серверный маршрут.
4. Проверить сценарии отдельного ID, группы, ошибки сохранения и переключения проекта, затем выполнить доступные проверки интерфейса и сборки.

## Автоматическое сопоставление при постобработке

1. Добавить вычисление и кэширование признаков сохранённых фотографий игроков проекта с привязкой к хешу изображения и модели ReID.
2. Извлекать признаки Track ID выбранного результата постобработки, не повторяя исходную GPU-инференцию, и сравнивать только с эталонами игроков проекта.
3. При включённой настройке сохранять подтверждённые автоматические назначения с указанием источника, оценки и версии; исключать неоднозначные совпадения, одновременные появления и конфликты с ручными решениями.
4. Добавить выключаемую настройку в блок постобработки и показывать состояние, отсутствие модели или эталонов и результаты сопоставления.
5. Проверить смену проектов и анализа, изменение модели и фотографий, повторную обработку, исправление вручную и конкурирующие запросы. Качество оценить отдельно на размеченном матче.
