# Project report implementation plan

**Goal:** Сводка всех розыгрышей проекта и карточки полного состава с медианным коэффициентом активности.

**Architecture:** Источник событий — timeline предпросмотра выбранной CPU-версии. Отдельный модуль считает уникальные контакты, действия и активность; project_report агрегирует видео. Существующий JavaScript выводит сводку и адаптивную сетку.

**Tech Stack:** Python, JavaScript, CSS, unittest, Node.

**Spec:** ../specs/2026-11-06-project-report-design.md

## Constraints

Без новых зависимостей, комментариев в коде, коммитов и изменения посторонних текущих правок. Пользователь разрешил реализацию в текущем рабочем каталоге; существующие незакоммиченные изменения сохраняются.

## Review focus

Полный состав с нулями; неизвестные контакты и исключённые ID; одинаковые имена; разные видео и CPU-версии; нулевая и чётная медиана.

## Execution ledger
