# Предпросмотр и отчёт проекта — план реализации

**Цель:** показать исходные и обработанные наблюдения, ограничить использование RAVEL для траектории и расширить отчёт по проекту.

**Архитектура:** использовать сохранённый SHA-проверенный CPU replay и его сырые GPU-кандидаты; решения и расчёты выполняются в Rust. Личности берутся только из подтверждённых привязок, виды касаний обозначаются как предварительные оценки.

**Ограничения:** не менять пользовательские данные и сохранённые снимки, не запускать повторный GPU, не добавлять комментарии в код.

1. Добавить проверяемую фильтрацию сырых кандидатов и переключатель отображения с порогами уверенности.
2. Ограничить отображаемые точки RAVEL короткими промежутками между пространственно совместимыми точками VballNet, проверить границы окон.
3. Дополнить проектную статистику числом розыгрышей, оценками ударов и видов касаний, средним по всем игрокам и отношением каждого игрока к ней; явно показывать отсутствие коэффициента при нулевом среднем.
4. Выполнить локальные проверки проекта и отдельно указать, какие проверки GPU и реального матча не запускались.
