# Volley Studio — работа с проектами

Локальный адрес: http://127.0.0.1:8765

Запуск из Windows: `start-volley-ui.cmd`. В WSL из корня репозитория:
`.venv/bin/python -m scripts.volleyball_ui`.

## Рабочий процесс

1. **Создать проект.** Нажмите «+ Создать проект» в правом верхнем углу.
   Только при открытии этого окна интерфейс проверяет доступные видео в `project/`.
   При обычной загрузке страницы все новые файлы не сканируются.
   Введите название (по умолчанию сегодняшняя дата в формате ДД.ММ.ГГГГ),
   отметьте одно или несколько видео из папки `project/` и нажмите «Создать проект».
   На этом этапе никаких технических параметров и диапазонов выбирать не нужно.
   Каждая запись изначально добавляется целиком.
2. **Анализ.** После создания откроется основной экран проекта.
   Карточками показаны его записи; выберите одну для просмотра. Здесь задаются
   все первоначальные параметры: модель обработки (ONNX/OpenVINO), автоматический
   либо ручной размер кадра, минимальная длительность розыгрыша, порог уверенности,
   CPU-потоки, профиль пляжного волейбола. У каждого видео своя шкала,
   выбор начала/конца обработки и предпросмотр кадра. Диапазоны можно сохранить
   перед запуском. Кнопка «Запустить анализ» обрабатывает все записи проекта
   последовательно, используя индивидуальные сохранённые диапазоны.
   Кнопка «Изменить видео проекта» позволяет менять состав проекта и название,
   но не параметры анализа.
3. **Игроки.** Выберите конкретную запись проекта, сравните фотографии track ID
   и объедините ID одного спортсмена под общим именем.
4. **Отчёт.** Суммарная статистика по обработанным записям проекта.
5. **Монтаж.** Единый ролик из самых зрелищных полных розыгрышей всех записей
   проекта, без обрезки эпизодов ради точной длительности.

При создании проекта нейросетевой анализ **не запускается автоматически**.

## Разрешение и шкала событий

Ориентация и размеры исходника считываются автоматически. Ширина кадра
для анализа по умолчанию не превышает 1280 px и ширину источника.
Высота определяется с сохранением пропорций; ручная настройка ширины доступна
в дополнительных параметрах.

На временной шкале зелёные блоки — приблизительные розыгрыши; оранжевые
метки — атаки, фиолетовые — блоки, бирюзовые — подачи, жёлтые — приёмы,
синие — верхние передачи. Границы и классификации эвристические и могут
быть неточными. Цветные метки появляются после анализа.

## Файлы

- `project/*.mp4` — исходные видео без изменения.
- `results/projects/projects.json` — проекты и диапазоны по записям.
- `results/projects/<project-id>/highlights.mp4` — итоговый монтаж.
- `results/projects/<project-id>/highlights_manifest.json` — отобранные розыгрыши.
- `results/projects/<project-id>/player_identities.json` — объединённые ID.
- `results/analysis/<cache-id>/` — сохранённый анализ.
- `results/player_photos/` — фотографии игроков.
- `results/ui_runs/` — журналы обработки.

UI слушает только localhost, без авторизации и без загрузки видео в интернет.
