# Volley Studio — работа с проектами

Локальный веб-интерфейс: http://127.0.0.1:8765

Запуск на Windows: `start-volley-ui.cmd` из корня репозитория.
В WSL: `.venv/bin/python -m scripts.volleyball_ui`.

## Как устроена работа

1. **Создать проект.** В правом углу шапки нажмите «+ Создать проект».
   Введите название (по умолчанию сегодняшняя дата в формате ДД.ММ.ГГГГ).
   В этом же окне отметьте одно или несколько видео из каталога `project/`.
   Для каждого выбранного видео задайте начало и конец **в секундах**.
   Изначально выбран весь файл. Нажмите «Создать проект».
2. **Видео и анализ.** Единственный глобальный переключатель в шапке — проект.
   На основном экране показаны только его видео в виде карточек. Нажмите на
   карточку для просмотра кадра, цветных меток действий и временной шкалы.
   Изменить границы можно здесь же и сохранить кнопкой «Сохранить диапазон».
   «Изменить видео проекта» открывает ту же форму для добавления/удаления записей.
   При запуске анализа обрабатываются все видео текущего проекта с сохранёнными
   индивидуальными границами; повторный анализ не запускается без необходимости.
3. **Игроки.** На этой вкладке выберите конкретное видео проекта, сравните
   фотографии track ID и присвойте нескольким ID имя одного человека.
   Номера track ID между разными исходными записями не считаются одинаковыми.
4. **Отчёт.** Суммарные события по обработанным видео проекта и имена игроков.
5. **Монтаж.** Общий рейтинг зрелищных розыгрышей из всех видео проекта,
   сохранение полных выбранных розыгрышей без подрезания ради точной длительности.

Если видео отсутствует в списке, добавьте его в `project/` и обновите страницу.
Исходные видео не перемещаются и не загружаются в интернет.

## Разрешение и предпросмотр

Ориентация и размеры исходного видео определяются автоматически.
Целевая ширина кадра анализа не превосходит 1280 px и по умолчанию не
превышает ширину источника. Высота рассчитывается с сохранением пропорций.
Ручная ширина доступна в дополнительных настройках.

На шкале зелёные интервалы обозначают приблизительные розыгрыши.
Оранжевые метки — атаки, фиолетовые — блоки, бирюзовые — подачи,
жёлтые — приёмы, синие — верхние передачи. Точность этих классификаций
зависит от трекера и разметки площадки. Отсутствие метки не доказывает
отсутствие действия.

## Где находятся файлы

- `project/*.mp4` — входные файлы.
- `results/projects/projects.json` — проекты, исходники и выбранные временные диапазоны.
- `results/projects/<project-id>/highlights.mp4` — общий видеомонтаж проекта.
- `results/projects/<project-id>/highlights_manifest.json` — выбранные розыгрыши по источникам.
- `results/projects/<project-id>/player_identities.json` — имена игроков и объединённые ID.
- `results/analysis/<cache-id>/` — кэш тяжёлого анализа.
- `results/player_photos/` — кэш изображений игроков.
- `results/ui_runs/` — журналы задач.


на открытый сетевой интерфейс.
