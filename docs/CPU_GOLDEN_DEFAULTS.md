# Золотые настройки CPU-постобработки

**Единственный источник параметров:** `scripts/volleyball_ui/static/cpu-defaults.json`.
Файл версионируется в Git. Текущий эталон: **revision 3**, 06.11.2026.

- При завершении **каждого нового GPU-инференса** автоматически создаётся отдельный CPU-снимок с этими настройками. Для моделей без головы Touch RAVEL-013 предусмотрен совместимый режим `baseline` без порога игроков.
- **Быстрый рилс** после собственного свежего инференса запускает CPU-постобработку на тех же настройках и монтирует из неё, сохраняя отдельный кэш. Его GPU-инференс не берётся из проекта.
- Кнопка **«Сброс настроек»** в предпросмотре восстанавливает значения эталона **в форме**, не запускает тяжёлые задачи и не удаляет версии. **«Пересчитать проект»** создаёт новый снимок, исходные GPU-предсказания не изменяются.
- Имя каждой новой CPU-версии формируется по времени начала её запуска: `ДД.ММ.ГГ ЧЧ:ММ`. Разные запускаемые конфигурации остаются самостоятельными снимками даже при одинаковом результате кэша.
- Профили GPU и настройки конкретных сохранённых CPU-снимков не меняют эталон. Изменения файла эталона **не пересчитывают** существующие снимки.

## Правило изменения эталона

Значения **не изменять из-за субъективного ощущения** или ради ускорения. Сначала взять одинаковые реальные фрагменты любительских матчей с ручной разметкой и сравнить кандидата с текущим эталоном: precision/recall касаний, точность границ розыгрышей, число ошибочных объединений и разрывов ID игроков. Изменять эталон только при подтверждённом улучшении конечного результата без неприемлемых регрессий, поднять `revision` и записать:
