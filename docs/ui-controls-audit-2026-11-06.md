# Проверка связей UI — 06.11.2026

Проверена цепочка от выбора в интерфейсе до параметров API и серверной обработки. Доступность определяется текущим проектом, выбранным кэшем, возможностями модели и состоянием единственного обработчика задач.

| Область | Исправленное правило |
| --- | --- |
| Цепочка проекта и анализа | Выбор сохраняет привязку к видео и версии; неготовые записи не становятся вариантами CPU-обработки. |
| Исходные и производные версии | Наличие CPU-результатов проверяется по файлам событий. Унаследованный признак `inference_only` не скрывает готовые дочерние версии. |
| Пользовательские списки | Отключённые нативные варианты не превращаются в активные строки меню. |
| Модели RAVEL | Порог голов недоступен для 011; порог Touch доступен только для 013. |
| Декодирование | Параметры FFmpeg недоступны при OpenCV. |
| ReID | Пороги и настройки сессии недоступны при выключенном сопоставлении; порог автопривязки зависит от её включения. |
| Ресурсы GPU | GPU-параметры недоступны, если оба движка работают на CPU. |
| Профили | Неактивные поля исключены из сохраняемых значений и сравнения изменений. |
| CPU-алгоритмы | Список определяется моделью и комплектностью файлов выбранного нейросетевого кэша; учитывается минимальный сохранённый порог Touch. |
| CPU-параметры | VballNet и Touch доступны только применяющим их алгоритмам. Запрет заполнения разрывов недоступен в combined и отправляется как false. |
| Сырые данные | Доступность источников и Touch обновляется при каждом переключении кэша, включая результат без CPU-обработки. Фильтр Touch учитывает порог записи. |
| Диагностика | Список видео ограничен обработанными результатами. Выбранный cache_id проходит через запрос, команду, чтение файлов и ссылку скачивания. |
| Формат диагностики | Параметры MP4 зависят от его экспорта; номер трека зависит от снимка; без выбранного выхода запуск недоступен. |
| Запуск задач | Анализ требует подготовленных видео. Пока сервер занят, новые анализ, монтаж, CPU-пересчёт, диагностика, рилс и бенчмарк не запускаются. Просмотр сохраняется. |

Проверки: 36 файлов JS-тестов и 86 Python-тестов прошли. Python использован из `.venv` в Ubuntu-25.04 WSL; OpenCV 5.0.0 установлен. Проверки syntax и diff-check прошли.

В браузере проверены переключение RAVEL 011/013, ReID off/amateur, OpenCV/FFmpeg, combined/ravel-geometry, форматы диагностики и фактические записи CPU-списка. Ошибок в консоли при проверенных действиях нет. Независимое ревью выполнено; найденные замечания исправлены и покрыты проверками.

Дорогие задачи инференса и экспорта на пользовательских видео не запускались. Их команды и передачу параметров проверяли изолированные тесты.
